# 看电视答题 App — 安装说明（给家长看）

看满 30 分钟 → 出 6 道题（语文、数学、英语各 2 道）→ 全部答对才能继续看，答错 1 道就休息 30 分钟。

- 默认家长 PIN 码：**8888**（装好后请第一时间改掉，见下面第 5 步）
- 适用：安卓电视 / 安卓电视盒子，安卓 7.0 以上（Android TV、普通安卓盒子都可以）
- 不联网也能用（内置题库）；电视联网时会自动从开源题库下载最新题目，题目可以常换常新

---

## 1. 把 APK 拷到电视上

APK 文件就是 `TVQuiz.apk`，任选一种方式：

**方法 A：U盘（最稳）**
1. 把 `TVQuiz.apk` 拷到 U 盘根目录
2. U 盘插到电视/盒子 USB 口
3. 在电视上打开「文件管理 / 媒体中心」，找到 U 盘里的 `TVQuiz.apk`

**方法 B：手机传**
- 用电视自带的「无线传屏 / 快传 / 发送到电视」类功能把手机里的 APK 发到电视，或先传到同一局域网的共享文件夹再在电视上打开。

## 2. 安装

1. 点开 `TVQuiz.apk` 开始安装
2. 如果提示“不允许安装未知应用”：去电视的
   `设置 → 安全与限制 / 应用 → 允许未知来源`，
   给「文件管理」打开允许安装的开关，再回来重新点安装
3. 安装完成，点「打开」
4. **升级安装**：从 v1.3.1 开始，新版本可以直接覆盖安装在旧版上（设置和计时不会丢）。但如果电视上装的是 v1.3 或更早的版本，第一次升到 v1.3.1 时会提示“签名不一致”装不上，需要先卸载旧版再装这一次——这是因为旧版本的打包签名每次都不一样，v1.3.1 起已改为固定签名，以后不会再出现这个问题。

> 不同品牌菜单名字略有不同：小米一般在安装时直接弹窗点「继续安装」；海信/TCL 在「设置 → 应用 → 特殊应用权限 → 安装未知应用」里开。

## 3. 第一次打开要做的事

1. 打开 App，点最上面的大按钮 **「开始看电视（开始计时）」**
2. 点了「开始」后，App 会自动跳到「显示在其他应用上层」的设置页，**请务必把本 App 的开关打开**，再按返回键回到 App。
   - **悬浮窗 / 显示在其他应用上层（必须开）**：安卓 10 以后，系统不允许后台运行的 App 直接弹出页面。看电视时本 App 在后台计时，时间一到要强制弹出答题页，就靠这个权限。**不开这个权限，到时间答题页弹不出来。** 首页下方会显示「强制弹窗权限已开启/未开启」，可以随时核对。
   - **通知权限**：允许（计时服务要在后台跑，靠它保活）
   - **使用情况访问（如果系统有提示）**：`设置 → 应用 → 特殊应用权限 → 使用情况访问` 里给「看电视答题」打开。本版本主要靠前台计时服务计时，这个权限是备用增强，没有这个菜单可以跳过。
   - **自启动 / 后台运行**：在电视的「应用管理 / 自启动管理」里给「看电视答题」打开自启动，并把电池/后台限制设为「不限制」，否则个别品牌会杀掉计时。
3. 把电视的信号源/桌面切回平时看的节目即可，App 会在后台计时。

## 4. 它是怎么工作的

- **计时**：屏幕亮着看电视时累计计时（默认 30 分钟，可改）
- **出题**：时间一到，全屏弹出答题页（若系统限制直接弹出，会先盖一个全屏的「时间到啦」页面，点「开始答题」进入），返回键关不掉。遥控器上下键选答案，按确认键答题。
  一共 6 题：语文 2 题 + 数学 2 题 + 英语 2 题，难度按所选年级（默认 2 年级）
- **全对**：马上解锁，开始下一个 30 分钟
- **答错任意 1 题**：进入休息锁屏，倒计时默认 30 分钟。倒计时存在手机（电视）本地，**关机重启也不会清零**，重启后会接着倒计时。倒计时结束会自动再出一次题，全对才能看。
- **题库**：题目实时来自开源题库 ChinaTextbookStudyFree（免费开源，按教材分年级整理）。App 每次打开时按所选年级自动下载该年级的题目（每个年级每科有数百到一千多道），下载成功就用在线题库；没网、下载失败时静默用内置题库（每个年级 30 题、共 180 题），答题永远不受影响。随机抽题，最近出过的题短期内不会重复。家长设置页上方会写明当前用的是「在线题库（开源仓库）」还是「内置题库」、一共多少题，也可以点「立即刷新在线题库」手动刷新一次。注意：1、2 年级的英语上游题库没有（英语教材三年级才开始），会自动用内置英语题，设置页会标注出来。

## 5. 家长入口：PIN 码

- **默认 PIN：8888**
- 入口有 3 个地方，都一样：
  1. App 首页点「家长设置（需要 PIN 码）」
  2. 答题页 / 锁屏页点下面的「家长入口（PIN）」
  3. 答题页 / 锁屏页 **长按遥控器菜单键**
- 在屏幕数字键盘上输 PIN（遥控器选数字按确认，也可直接按遥控器数字键）
- PIN 输对后：
  - 在答题页/锁屏页：立即解锁并重置计时
  - 在首页：进入家长设置，可以改：
    - **年级**：1 / 2 / 3 / 4 / 5 / 6 年级（点按钮循环切换），按自家孩子的年级选
    - **每轮观看时长**：15 / 30 / 45 / 60 分钟
    - **答错休息时长**：10 / 20 / 30 / 45 / 60 分钟
    - **题库**：设置页会显示当前题库来源（在线题库/内置题库）和题目总数；点「立即刷新在线题库」可马上联网更新一次
    - **PIN 码**：改成 4–8 位数字，输好后点「保存新 PIN 码」——请把默认 8888 改掉，别让孩子猜到
    - 重置计时、停止计时监控

## 6. 卸载

先用家长 PIN 解锁/在家长设置里点「停止计时监控」，再去电视
`设置 → 应用 → 看电视答题 → 卸载`。
直接卸载也可以（本 App 没有做设备管理员强制防卸载），但请先解锁，避免锁屏倒计时状态残留造成困惑——卸载后所有计时和倒计时都会随 App 一起清除。

## 7. 常见问题

- **按 Home 键回到桌面还能看别的 App 吗？**
  本版本没有做“设备所有者（Device Owner）”级别的强制锁定，孩子按 Home 键理论上可能切到桌面。但计时服务还在后台跑：锁屏/答题时间到时它会再次把全屏页面拉到前面；锁屏倒计时也存在本地不会清零。要做到 Home 键也完全锁死，需要把电视盒子做 Device Owner 配置（会恢复出厂、步骤复杂），普通家庭一般不需要。
- **重启电视能绕过休息吗？** 不能。锁屏结束时间是按时间戳存的，重启后 App 自启动会接着倒计时。
- **没网能用吗？** 能。App 申请了联网权限，但只用来下载题库；没网时用内置的 180 题出题，其他功能完全不受影响。
- **题目会更新吗？** 会。题目来自开源题库 ChinaTextbookStudyFree，那边更新了题目，电视上的 App 下次打开时就会自动抓到新题，不用重装、不用做任何操作。在家长设置里能看到当前题库来源和题数，显示「在线题库（开源仓库）」就是抓成功了。下载走的是 jsDelivr 等多条线路（国内优化过的通道），偶尔某条线路不通会自动换下一条；实在都拉不到时就继续用内置题库，属正常现象，过段时间打开又会再试。
- **题目太难/太简单？** 在家长设置里把年级调低/调高一级即可。
- **时间到了却没有弹出答题页？** 十有八九是「显示在其他应用上层」权限没开：打开 App 看首页下方是否显示「强制弹窗权限未开启」，是的话点「开始看电视」按提示打开开关；个别品牌还要在应用权限里另开「后台弹出界面」。
- **安装新版本时提示“签名不一致”/装不上？** 如果旧版是 v1.3 或更早版本，先卸载旧版再装新版（只需这一次）；v1.3.1 之后的版本之间可以直接覆盖安装。
